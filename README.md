# 스마트 가계부 웹 앱 (House Account Book Web App)

React, TypeScript, Tailwind CSS, Recharts 기반으로 개발된 반응형 수입·지출 통합 자산 관리 웹 애플리케이션입니다.

---

## 🌟 주요 기능 및 구현 특징

### 1. 2단계 카테고리 시스템 (Lookup Table)
- **지출 (12개 대분류)**:
  - 식비: 외식, 식재료(마트), 배달, 카페/간식
  - 주거/통신: 월세/관리비, 공과금, 통신비
  - 생활/용품: 생활용품, 가전/가구, 의류/미용
  - 쇼핑: 백화점/아울렛, 온라인쇼핑, 멤버십/포인트
  - 교통/차량: 대중교통(버스/지하철), 기차/고속버스, 전기차충전/주유, 통행료/주차, 차량정비
  - 교육비: 학원비, 교재비, 온라인강의
  - 가족: 용돈, 모임/행사, 육아
  - IT/구독: AI/소프트웨어, 클라우드/웹서비스, 콘텐츠(넷플릭스 등)
  - 문화/여가: 영화/공연, 취미/기기
  - 여행/휴가: 숙박, 항공/교통, 관광/입장권
  - 건강/의료: 병원/약국, 운동/피트니스
  - 금융/기타: 보험, 저축/투자, 경조사/회비, 미분류
- **수입 (3개 대분류)**:
  - 급여: 월급, 상여금/보너스, 수당
  - 금융/부수입: 이자/배당금, 투자수익, 중고거래
  - 기타 현금: 용돈, 축하금, 기타수입/미분류
- 헤더의 **'카테고리 설정'** 버튼을 통해 언제든지 대분류별 소분류를 추가하거나 기본값으로 복원 가능

### 2. 수입 / 지출 통합 입력 모듈 (3가지 탭)
- 상단 **`[ 지출 입력 | 수입 입력 ]`** 토글 스위치 제공 (선택 유형에 따라 대/소분류 드롭다운 자동 갱신)
- **직접 입력 탭**: 날짜, 대분류, 소분류, 내용, 금액, 메모 입력
- **텍스트 입력 탭**:
  - 카드사 결제 문자(SMS) 및 카카오톡 알림톡 붙여넣기 지원
  - 정규표현식으로 날짜, 금액, 사용처 자동 추출
  - 사용처 키워드 기반 카테고리 자동 유추 및 입금/승인 여부에 따른 수입/지출 유형 자동 선택
  - 편리한 테스트를 위해 5종의 대표 예시 문자(국민카드, 신한카드, 카카오페이, 급여 입금, 당근마켓) 원클릭 테스트 지원
- **영수증 사진 탭**:
  - 파일 업로드 및 이미지 미리보기, 확대/삭제 기능
  - AI 영수증 모의(Mock) OCR 스캔 시뮬레이션 및 데이터 자동 채우기

### 3. 월별 대시보드 (KPI & 차트 & 요약표)
- 헤더의 `◀ 2026년 9월 ▶` 컨트롤러로 월별 데이터 필터링
- 3대 핵심 KPI 카드:
  - 💰 **월 총 수입액** (+ 금액 및 건수)
  - 💳 **월 총 지출액** (- 금액, 건수 및 전월 대비 증감률)
  - ⚖️ **이번 달 잔액(수입 - 지출)** (수입 대비 잉여율/초과율 표기)
- **Recharts 기반 도넛 차트**:
  - `[지출 비중 | 수입 비중]` 탭 전환 지원
  - 중앙 인터랙티브 정보(총액 및 호버 카테고리 정보) 표기
- **카테고리 요약 표**:
  - 금액순 정렬, 비중(%), 프로그레스 바 표시
  - 행 클릭 시 하단 거래 리스트가 해당 카테고리로 즉시 필터링 연동

### 4. 엑셀 스타일 내역 리스트
- 컬럼 구성: `유형` | `날짜` | `대분류` | `소분류` | `내용(사용처/입금처)` | `금액` | `관리`
- **시각적 구분**:
  - 수입: 파란색 텍스트 및 `+` 부호 (`+ 4,200,000원`), 파란색 배지
  - 지출: 빨간색 텍스트 및 `-` 부호 (`- 14,500원`), 빨간색 배지
- **필터 & 검색**:
  - `전체` / `지출만` / `수입만` 필터 탭
  - 카테고리 드롭다운 필터
  - 실시간 키워드 검색
  - 날짜순 / 금액순 정렬 (오름차순/내림차순)
- **엑셀 CSV 내보내기**: UTF-8 BOM 지원으로 한글 깨짐 없이 Microsoft Excel에서 즉시 열람 가능한 CSV 다운로드
- **인라인 관리**: 모달을 통한 내역 수정 및 안전한 삭제 확인

## 🚀 실행 방법

### 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속합니다.

### 프로덕션 빌드 및 미리보기
```bash
npm run build
npm run preview
```
